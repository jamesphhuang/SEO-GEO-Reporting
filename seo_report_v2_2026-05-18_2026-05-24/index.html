Executive Summary

2 分鐘摘要

本週最大風險是技術訊號不一致：Ahrefs 抓到 94 筆 double slash URL，Screaming Frog current crawl 則未重現，但 SF 同時抓到 94 筆 hreflang missing self reference，顯示問題很可能藏在 hreflang URL 產生邏輯。最大成長機會在高排名低 CTR 頁面，尤其 `/online-store/features`、`/faq/about`、`/showcase`。AI 搜尋方面，Workduo 顯示 SHOPLINE 在 AI 平台可見度尚可，但自站 citation share 偏低，應用可被 AI 引用的比較型與定義型內容補強。

P1score 15Technical SEO

94 double slash URLs

問題Ahrefs 發現 94 筆 `https://shopline.tw//...` URL，SF current crawl 則顯示 Multiple Slashes = 0，代表來源訊號可能集中在 hreflang/canonical 或特定 crawl path。
影響URL 訊號被拆散，可能造成 hreflang self-reference 缺失、canonical 混淆與 crawl waste。
預計成果Indexable pages +10-20；crawl waste -20-40%。
怎麼做統一產生單斜線 URL；更新 hreflang/canonical/internal links；保留 301 作防線；修完後用 Ahrefs 與 SF 雙源複測。

Evidence: Ahrefs double slash 94；SF Multiple Slashes 0；SF hreflang missing self 94。

P1score 15Technical SEO

Hreflang self reference

問題94 個頁面缺少指向 canonical 單斜線 URL 的 hreflang self-reference，多筆 hreflang URL 仍指向雙斜線。
影響國際版本關聯訊號不完整，可能讓 Google 對語系/地區頁判斷不穩定。
預計成果International indexing errors -50-80%。
怎麼做每頁輸出 canonical URL 的 self-referencing hreflang；同步檢查 x-default 策略；部署後重跑 SF hreflang report。

Evidence: SF Hreflang Missing Self Reference 94；Missing X-Default 81。
